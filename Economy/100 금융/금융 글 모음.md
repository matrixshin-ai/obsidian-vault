은행의 자기자본

CET1 

1. CET1 (Common Equity Tier 1) 비율이란? 

정의: 

CET1 비율은 은행의 핵심 자기자본(Common Equity Tier 1) 을 위험가중자산(RWA, Risk-Weighted Assets) 으로 나눈 비율입니다. 

CET1 비율 = ( Common Equity Tier 1 / Risk-Weighted Assets ) × 100
 

구성요소: 

- CET1 자본: 보통주 자본(Common Shares), 이익잉여금(Retained Earnings), 기타 적립금 등 손실 흡수 능력이 가장 높은 자본 
    
- RWA: 자산의 위험도에 따라 가중치를 부여한 총 자산 
    

기준: 

- 바젤 III 기준으로 최소 4.5% 이상, 각국은 별도로 추가적인 보수적 비율을 적용 (한국은 보통 7~9% 수준 요구) 
    

중요성: 

- 은행이 위기에 처했을 때 즉시 손실을 흡수할 수 있는 능력을 나타냄 
    
- 신뢰성 있는 은행의 기본 조건 
    
- 스트레스 테스트에서 가장 중요한 지표 중 하나 
    

  

2. CET1 vs. 총 자기자본비율 (Total Capital Ratio) 비교 

|   |   |   |   |   |
|---|---|---|---|---|
|구분|정의|포함 자본 항목|최소 기준 (Basel III)|중요성|
|CET1 비율|가장 핵심적인 자기자본 비율|보통주 자본만 포함|4.5%|손실흡수능력, 유동성 위험 대응력|
|Tier 1 비율|기본자본 비율|CET1 + 추가 Tier 1 자본 (AT1, 주로 영구채)|6.0%|단기 위기대응 자본력|
|총 자기자본비율 (Total Capital Ratio)|총 자기자본을 기반으로 한 비율|Tier 1 + Tier 2 (후순위채 포함)|8.0%|전반적인 건전성, 장기 리스크 대응|

  

3. 장기성 자금의 중요성 

정의: 

장기성 자금이란 만기 1년 이상 또는 만기가 없거나 상환청구권이 없는 자본성 자금으로, 주로 자본조달 또는 장기투자에 활용됩니다. 

🔹 중요성 항목별 정리 

|   |   |   |
|---|---|---|
|항목|설명|왜 중요한가?|
|① 유동성 관리|단기 자금 위기 시 자금 이탈 가능성이 적음|안정적인 유동성 확보, 뱅크런 방지|
|② 자기자본 인정 여부|영구채, 후순위채 등은 Tier 1 또는 Tier 2로 인정 가능|자기자본비율 제고 수단|
|③ ALM (자산부채 관리)|자산과 부채의 만기 구조를 조정|만기 불일치 리스크 감소|
|④ 투자 여력 확보|장기 대출·투자 프로젝트에 투입 가능|금융기관의 중장기 수익원 확보|
|⑤ 신용등급 방어|장기성 자금은 신용등급 평가 시 긍정 요소|조달비용 절감 및 시장 신뢰 유지|

SSA 스타일 발행

기존 이머징마켓(EM) 방식 대신 SSA 발행 스타일로.. 

SSA 발행사는 글로벌 채권시장에서 국공채에 준하는 위상을 인정받는다. 초우량 발행물로 인정받는 만큼 중앙은행과 국부펀드, 연기금, 은행 트레저리 등이 주로 투자한다. 

아시아에서 SSA 발행 시장에 진입한 곳은 일본 정책금융기관 정도였다. 이어 24.5월 KDB산업은행이 SSA 스타일로 발행을 마치면서 해당 시장으로 자리를 옮겼다.
