# 한국 노동시장 — 전체 고용 견고, 청년·건설 취약

전체 실업률과 고용률은 견고하지만 청년층 NEET 비율과 건설업 지속 감소가 구조적 약점이다.

## 주요 고용 지표

| 지표 | 수치 |
|---|---|
| 전체 고용률 (2025) | **62.9%** |
| 15~64세 고용률 | ~70% |
| 전체 실업률 | 2.8% |
| 청년(15~29세) 실업률 | 5.5% |
| **청년 NEET 비율** | **18.8%** (OECD 평균 14%) |
| 월평균 임금 | 400만 원 수준 |

## 청년 NEET 문제의 특수성

한국 NEET의 특징은 **대졸 이상 학력자 비중이 높다**는 점 (OECD 평균은 저학력자가 주류). 취업을 원하지만 대기업·공공부문 선호가 강해 중소·서비스업 미스매치가 심각.

## 산업별 고용 동향

| 산업 | 동향 |
|---|---|
| 보건복지·사업서비스·전문과학 | 꾸준히 증가 (서비스 고용 견인) |
| 자동차·의약품·식료품 일부 제조업 | 증가 |
| 건설업 | **21개월 연속 감소** (2025.4 기준) |
| 내국인 제조업 전체 | 20개월 연속 감소 |
| 섬유·금속·기계장비·전기장비 | 지속 감소 |

건설업 21개월 연속 감소는 [[concepts/korea-investment|건설투자 -9.9%]]와 직접 연결된다.

## 연령별 구조적 불균형

- 30·40·60세 이상 고용률 **상승**
- 청년(15~29세) 고용률 **45.3%**, 전년 대비 0.9%p 하락
- 구인배수 0.5 내외 — 구직자 1인당 일자리가 절반에 불과

**60대+ 고용이 청년 고용을 대체**하는 현상: 고령화가 진행되면서 저임금·단순 서비스직 고령 취업이 늘고, 청년이 원하는 질 높은 일자리는 부족한 이중 구조. ^[inferred]

## [[concepts/korea-low-growth-trap|저성장과의 연결]]

[[concepts/korea-low-growth-trap|TFP 둔화]]의 노동시장 측면: 노동시장 이중구조(정규/비정규, 대기업/중소기업 격차)가 인적자본 축적과 재배치를 제약. 비정규 고용 비중이 높으면 기업의 훈련투자 유인이 약해 장기 생산성 개선이 더딤.

## 취약부문 스트레스 (2025.12)

- 실업률 4.1%, 실업자 121.7만 명 (+10.3만 명 YoY)
- 고용률(15~64세) 61.5%
- 건설·내수 연관 업종이 지속 취약
- 노동시장은 "붕괴"보다 완만한 둔화·이질화 경로 전망 ^[inferred]

## 구조적 과제

| 문제 | 내용 |
|---|---|
| 비정규직 비중 | **28.3%** (OECD 평균 **11.8%**, 1위) |
| 합계출산율 | 0.72 (2023) — 노동력 감소의 구조 원인 |
| 대기업-중소기업 임금 격차 | 미스매치 심화 |
| AI·디지털 전환 | 직업훈련·재교육 시스템이 기술 변화를 따라가지 못함 |

## 통상임금 판결 (2024년 12월 대법원)

2013년 대법원은 통상임금 조건을 **정기성·일률성·고정성** 3요건으로 제시했다.

2024년 12월 판결: **고정성 요건 제외** — 명절 상여금·정기 상여금도 통상임금에 포함.

영향: 실질 통상임금 범위 확대 → 연장·야간·휴일근로 수당 기준 인상 → 기업 인건비 부담 증가. ^[inferred]

## 2025년 4분기 임금일자리 동향 (2026-05-19 발표)

전체 임금일자리: **2,112만3천개** (+22만1천개, 전년동기비)

| 연령대 | 증감 |
|---|---|
| 60대 이상 | **+24만6천개** (주도) |
| **30대** | **+9만9천개** (역대 최대 증가폭) |
| 50대 | +2만4천개 |
| **20대 이하** | **-11만1천개** (13분기 연속 감소) |
| 40대 | -3만7천개 (10분기 연속 감소) |

- 20대 일자리 감소 원인: 제조업(-3.1만), 건설업(-1.7만), IT(-1.6만)
- 30대 역대 최대 증가 배경: 일자리 진입 시점이 20→30대로 지연, 30대 인구 증가 + 여성 보건·복지 일자리 증가
- **건설업**: -8만8천개, **9분기 연속 마이너스** (두 자릿수 감소에서 벗어나 감소폭 소폭 축소)
- 보건·사회복지: +12만6천개 (최대 증가)
- 제조업: -1만4천개 (4분기 연속 감소)

## 성과급 논쟁 (2026년 조선·중공업 초호황기)

장기 불황 후 초호황에 진입한 중후장대 업종의 성과급 구조 변화:
- **HD현대중공업** 노조: '영업이익 최소 30% 성과 공유' 요구 (영업익 3.6조 가정 시 1조원 초과)
- **두산에너빌리티**: 성과급 지급방식 개선을 별도 요구안으로 분리 제출
- **HD현대일렉트릭**: 성과급 산정 기준을 기본급 → 실질연봉으로 변경
- 배경: 반도체 성과급 수준이 타 업종의 암묵적 기준점(benchmark)으로 작용
